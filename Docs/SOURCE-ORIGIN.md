# Source origin and delivery scope

Dynamic Stage X / com.tsangbaby.dynamicstagex is a new independent source implementation written for Tsangbaby at the user's request. No original product source was supplied. The user-supplied demonstration and read-only binary findings informed behavior goals and system-interface research, not a function-by-function translation.

This source tree does not redistribute the Dynamic Stage binary, resources, identities, original video, Apple SDK, Frida artifacts, third-party runtime or downloaded public runtime headers. Minimal API declarations and runtime type checks are written in our own bridge. Fixed external header URLs/hashes are documented as research evidence; raw research caches remain local and outside the exported snapshot.

No open-source license or public release has been selected by the user. Source delivery does not itself authorize publishing a repository, reusing third-party code outside its terms, signing/installing a package, or modifying a device.
